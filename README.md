# Wisps releases

Release builds of Wisps: persistent Linux microVMs you can run next to the services they depend on.

Install or update the CLI:

```bash
curl -fsSL https://github.com/akramh/wisps-release/releases/latest/download/install-cli.sh | sh
```

Each release has the CLIs (`wisp`, `wisp-admin`), the fleet service, host and deploy bundles, the installers and `SHA256SUMS`. This repository holds releases only.
